# КорпМессенджер

Корпоративный мессенджер: **сервер (Python/Flask + WebSocket)**, **десктопный клиент (Electron, Windows 7 SP1 / 10 / 11)** и **мобильный клиент (Kivy → APK, Android 5.0+)**.

## Возможности
- Регистрация и вход; адрес сервера и порт указываются вручную на экране входа.
- Личные сообщения, групповые чаты, контакты («добавить сотрудника», поиск по каталогу).
- Смайлы: панель эмодзи + автозамена текстовых смайликов `:) :D :( ;) <3 +1` и т.д.
- Отправка файлов (до 50 МБ), просмотр картинок, скачивание документов.
- Статусы «в сети / отошёл / не в сети» (+ авто-«отошёл» при бездействии).
- Уведомления о новых сообщениях/чатах: анимированный бейдж непрочитанных, счётчик в заголовке окна, всплывающие тосты, системные уведомления в Electron, вибрация в мобильном клиенте.
- Управление группами: добавить/исключить участника, повысить до админа группы, переименовать, удалить группу.
- Права: пользователь может удалять свои сообщения; **админ** — сообщения всех, управлять сотрудниками и всеми группами (полная админпанель: статистика, блокировки, роли, модерация, файлы).
- Шрифт сообщений крупный (22–24 px/sp) — интерфейс «не мелкий».
- Если WebSocket недоступен, клиент автоматически опрашивает сервер каждые 4 секунды (фолбэк).

## Структура
```
server/   — Flask + Socket.IO сервер, веб-клиент (static/), .bat для Windows
client/   — Electron-клиент (Win7 совместимость: Electron 22, сборка ia32)
mobile/   — Kivy-клиент + buildozer.spec для сборки APK
docs/     — API-справка
```

## Быстрый старт (Windows)
1. Установите Python 3.8+ (для Windows 7 — последняя версия 3.8.10, 32 бита).
2. `server\install_server.bat` — создаст venv и поставит зависимости.
3. `server\run_server.bat` — запустит сервер на порту **5000**.
4. Откройте `http://127.0.0.1:5000` (или адрес сервера в локальной сети) — войдите: **admin / admin123**.

Десктоп: установите Node.js 16.x (последний для Win7), затем `client\run_client.bat`.
APK для Android: Linux + `pip install -r mobile/requirements.txt`, затем `cd mobile && buildozer android debug`.

## Безопасность
- Пароли: PBKDF2-SHA256, 120k итераций, индивидуальная соль.
- Доступ к файлам — только участникам чата, где они опубликованы (или админу).
- Имена файлов санитизируются; хранение — случайные имена в `server/uploads/`.
- Для production поставьте сервер за HTTPS-прокси (nginx/IIS) и смените SECRET_KEY.

Подробнее по API — в `docs/API.md`.
